# Rail Ninja Automated Tests

## Общее описание проекта

Проект предназначен для автоматизации тестирования веб-приложения **Rail Ninja**.
Используются следующие технологии:

* **Java 17**
* **Gradle** для сборки и управления зависимостями
* **Selenium WebDriver 4**
* **Cucumber 7.18** для BDD сценариев
* **JUnit 5** для организации тестов
* **Allure** для отчетности
* **SLF4J + Logback** для логирования
* **WebDriverManager** для управления драйверами браузеров
* **Rest Assured** для API тестирования

Проект реализует автоматические тесты для сценариев бронирования билетов и API, включая:

* Выбор маршрута и даты поездки
* Выбор поезда и пассажиров
* Заполнение данных пассажира
* Проверку работы кнопки Continue и валидации формы
* Проверку email-поля пассажира
* Проверку REST API

---

## Тестовые сценарии

### UI Тесты

1. **Changing data on Rail Ninja**

    * Проверка изменения имени взрослого пассажира.

2. **Passenger prove mail**

    * Проверка успешного заполнения и подтверждения email.

3. **Passenger enter incorrect mail**

    * Проверка валидации email.

4. **Empty form**

    * Проверка поведения при пустой форме пассажира.

5. **Fill form and press continue**

    * Проверка, что полностью заполненная форма позволяет перейти к следующему шагу.

### API Тесты

* Проверка корректности работы REST API Rail Ninja.
* Валидация ответов API, статус-коды, формата JSON.
* Тестирование различных сценариев, включая некорректные запросы и ошибки.

## Сборка и запуск тестов

### 1. Клонирование проекта

```bash
git clone <URL_репозитория>
cd <имя_проекта>
```

### 2. Сборка проекта через Gradle

```bash
./gradlew clean build
```

### 3. Запуск UI и API тестов

#### Через Gradle

```bash
./gradlew test
```

#### Через интерфейс IDE (IntelliJ IDEA)

1. В панели **Project** открой `src/test/java`.
2. Найди пакет или класс тестов (например, `RailNinjaTest.java`).
3. **ПКМ → Run 'Tests in RailNinjaTest'** для запуска всех тестов в классе или пакете.
4. Результаты тестов появятся в панели **Run**.
5. Можно также настроить конфигурацию: **Run → Edit Configurations → + → JUnit → выбрать класс/пакет → OK → Run**.


## Требования

* Java 17
* Gradle 7+
* Google Chrome и совместимый ChromeDriver
* Сетевое подключение для доступа к Rail Ninja
* Рекомендуется использовать отдельный профиль Chrome для автоматизации
